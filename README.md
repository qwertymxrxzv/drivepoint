# DRIVEPOINT

Русскоязычный демонстрационный лендинг автосервиса для портфолио. На сайте шесть услуг, информация о подходе и этапах обслуживания, галерея с увеличением, форма записи и пример контактного блока со схемой.

## Как запустить

Откройте `index.html` двойным щелчком. Сайт работает без установки пакетов, сборки и подключения к интернету.

Для проверки через локальный сервер откройте PowerShell в папке `drivepoint` и выполните команду, если установлен Python:

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

Откройте в браузере `http://127.0.0.1:8000`. Чтобы остановить сервер, нажмите Ctrl+C в PowerShell.

## Как устроен сайт

- `index.html` содержит тексты, ссылки, поля формы и порядок разделов. Здесь же можно изменить подписи галереи, заголовок и описание страницы.
- `styles.css` отвечает за оформление и перестроение блоков на узких экранах. Основные цвета заданы в начале файла через `--bg`, `--text` и `--accent`.
- `script.js` управляет мобильным меню, подстановкой услуги, проверкой формы и переключением фотографий. Форма проверяет поля в браузере и очищает их после успеха. Приложение не отправляет и не хранит введённые данные.
- `assets` содержит WebP-изображения и SVG-значок сайта. Чтобы заменить фото, сохраните новое в этой папке и обновите путь, размеры и `alt` в HTML. Для галереи обновите также `href` ссылки. Первый экран использует `hero.webp` и отдельную мобильную версию `hero-mobile.webp`.
- `favicon.ico` — запасной значок вкладки, который браузер запрашивает при открытии фотографии напрямую.

Адрес, номер телефона и режим работы вымышлены. Схема в контактах иллюстрирует место для карты. Изображения сгенерированы для проекта.

## Как проверить изменения

1. В Chrome нажмите F12 и включите режим устройств. Проверьте ширины 320, 390, 768, 1024 и 1440 px. Кнопки должны оставаться видимыми, а страница не должна прокручиваться по горизонтали.
2. Откройте мобильное меню и выберите раздел. Нажмите «Записаться» в карточке и проверьте, что в форме выбрана нужная услуга.
3. Проверьте пустую форму, затем заполните её вымышленными данными. Подойдёт номер `+7 (000) 000-00-00`. После успешной проверки поля очистятся, а форма сообщит, что заявка не отправлена.
4. Откройте фото и переключите его кнопками или стрелками на клавиатуре. Закройте окно клавишей Esc. Проверьте вкладку «Консоль» на наличие ошибок.

## Бесплатное размещение

- **Cloudflare Pages.** Выберите Direct Upload и загрузите папку с `index.html`, `styles.css`, `script.js`, `favicon.ico` и `assets/` в корне. [Инструкция Cloudflare](https://developers.cloudflare.com/pages/get-started/direct-upload/)
- **GitHub Pages.** Положите файлы сайта в корень публичного репозитория. В Settings → Pages выберите публикацию из ветки и папку `/(root)`. [Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
